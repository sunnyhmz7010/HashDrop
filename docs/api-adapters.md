# 预置 API 适配器

首版没有预装业务开通适配器，API 商品可以保存为下架草稿，但不能上架。需要指定真实业务服务、开通参数、鉴权、幂等与查询协议后再实现适配器；不会把任意 URL 或脚本当成商品配置。

适配器实现 `backend/delivery.go` 的 `APIAdapter`，在 `main.go` 的 `App.adapters` 中按固定名称注册。使用代码固定的服务地址、独立 HTTP 超时及禁止重定向的客户端；密钥从受限服务端凭据读取。`Validate` 校验非敏感 `parameters`；产品中只保存适配器名称和非敏感参数，订单创建时复制为快照。

```json
{"adapter":"已部署名称","parameters":{"plan":"basic"}}
```

一份商品对应一个稳定的 `订单号:序号` 幂等键。`ReplaySafe()` 返回 true 之前，必须确认外部服务会复用此键，或适配器能先查询原操作再决定执行；查询结果未知时也不能重新开通。`APIResult.RetrySafe` 只用于已经确认本次请求没有副作用的失败，不能仅因 HTTP 超时而返回 true。

结果不明的非幂等调用转 `manual`，重启后仍保持人工处理。可重放任务采用最多五次自动调用，间隔递增；人工重试需要支持安全重放的适配器，仍复用原幂等键。已成功交付的任务永远不重复执行。业务结果保存到数据库前重新加密，外部错误原文和响应不写日志，也不回传购买者。
